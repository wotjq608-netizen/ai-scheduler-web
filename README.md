# 🌿 개인 AI 일정관리 대시보드

자연어로 말하면 AI가 일정을 자동 추가해주는 개인 대시보드입니다.

## ✨ 주요 기능

- 🤖 **AI 자연어 일정 추가** — "내일 오후 2시 치과 예약 추가해줘"처럼 말하면 자동 등록
- 📅 **월간 캘린더** — 날짜별 일정 확인 및 관리
- ✅ **완료 체크** — 할일 완료 처리
- 🌤️ **실시간 날씨** — 서울 날씨 및 추천 복장
- 📦 **이월 기능** — 미완료 일정을 다른 날로 이동
- 🔒 **로컬 저장** — 모든 데이터는 내 브라우저에만 저장 (서버 없음)

## 🚀 사용 방법

1. 사이트에 접속
2. ⚙️ **API 설정** 버튼 클릭
3. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료 Gemini API 키 발급
4. API 키 입력 후 저장
5. 자연어로 일정을 입력하면 AI가 자동 분석!

> API 키 없이도 기본 키워드 분석으로 일정 추가 가능

## 🛠️ 기술 스택

- **순수 HTML/CSS/JavaScript** (프레임워크 없음)
- **Gemini 2.0 Flash API** (AI 자연어 분석)
- **Open-Meteo API** (날씨, 무료)
- **localStorage** (로컬 데이터 저장)
- **GitHub Pages** (무료 호스팅)

## 📂 원본 프로젝트

원본은 FastAPI + SQLite + 카카오 로그인 기반의 풀스택 서버 애플리케이션이었으며,  
GitHub Pages 배포를 위해 순수 프론트엔드로 변환되었습니다.
